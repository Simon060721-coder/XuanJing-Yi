# 玄镜易命理算法文档

## 1. 梅花易数算法

### 1.1 起卦规则

时间起卦：
```
年数 + 月数 + 日数 + 时数 = 总数
上卦 = 总数 % 8（余数为0时按8计）
下卦 = (日数 + 时数) % 8
动爻 = 总数 % 6
```

### 1.3 五行生克

相生：金→水→木→火→土→金
相克：金克木 木克土 土克水 水克火 火克金

## 2. 五行平衡度算法

```
Balance = (max_element - min_element) / total

< 0.2：完全平衡
0.2-0.4：基本平衡
0.4-0.6：需要调和
> 0.6：严重失衡
```

## 3. 综合评分算法

基础分60，根据卦象、体用、五行、动爻等因素调整。

分级：
- 85-100：吉
- 70-84：平吉
- 50-69：平
- 30-49：平凶
- 0-29：凶
