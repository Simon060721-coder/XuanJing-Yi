# 龟壳素材规格

本文件说明如何提供龟壳素材，以及需要满足的尺寸、构图与对齐要求。
**目标是：你把文件放到指定位置即可生效，不需要改任何代码。**

代码里的唯一开关是 `frontend/src/config/turtle.ts`。

---

## 一、两种素材路线

| 路线 | 素材 | 状态 | 代价 |
|------|------|------|------|
| **PNG 手绘/3D 渲染图** | 透明底 PNG | **已接入，可直接用** | 无 |
| **3D 模型（.glb）** | glTF 二进制 | **未接入** | 需引入 three.js / react-three-fiber（约 +600KB 依赖 + 一块 WebGL 画布） |

如果你要走 3D，请先告知，我再接。下面是 PNG 路线的完整规格。

---

## 二、放置位置

```
frontend/public/assets/turtle-shell.webp
```

文件名与路径**已写在配置里**（`config/turtle.ts`）。文件放进去就自动启用；文件不存在时组件会**自动回退到内置矢量版**并在控制台留一条提示，不会报错、不会白屏。

要换文件名或换路径，改 `config/turtle.ts` 里的 `src` 即可。

---

## 三、PNG 规格

| 项 | 要求 |
|----|------|
| 格式 | **WebP 带 Alpha**（首选，同画质体积约为 PNG 的 1/5）或 PNG-24 |
| 背景 | **完全透明**。不要画背景、不要画桌面、不要画投影（投影由页面加） |
| 建议尺寸 | **900 × 529 px**（页面按 300 px 宽显示，3× 有余量） |
| 宽高比 | 当前素材为 1.70:1。若不同，需在 `config/turtle.ts` 同步改 `width` |
| 左右 | **必须水平居中**——铜钱自中线落下，图形偏了就对不齐 |
| 边距 | 四周留约 **8% 透明边距**，供摇晃动画的位移使用，避免被裁切 |

> 已接入的素材是 AI 生成图（原图右下角有「豆包AI生成」水印，抠图时已随背景一并裁掉）。
> **AI 生成图同样可能有使用条款限制，商用前请自行确认。**

## 四、构图与对齐（最关键）

```
        672 × 480（2×）
   ┌────────────────────────────────┐
   │        ← 约 8% 透明边距 →       │
   │    ┌──────────────────────┐    │
   │    │                      │    │
   │    │      甲 背 主 体      │    │  ← 顶光偏左，暗部在右下
   │    │                      │    │
   │    │                      │    │
   │    │        ◉ 出钱口       │    │  ← 位于图片高度的约 70–75%
   │    │                      │    │
   │    └──────────────────────┘    │
   │                                │
   └────────────────────────────────┘
              ↕ 三枚铜钱落在这里
```

- **出钱口（腹甲开口）应位于图片高度的约 70–75% 处**，且水平居中。
- 角度建议：**略俯视**——既能看到甲背纹理，又能看到朝下的开口。
- 铜钱的落点是**页面**按中线计算并排成 −104 / 0 / +104 px 三格；素材只需保证开口在中线上。

### 开口位置不一样怎么办

不必重画。改 `config/turtle.ts` 的 `mouthTopPx`（单位 px，自舞台顶部算，内置版是 176）：

```ts
export const TURTLE_ASSET: TurtleAsset | null = {
  src: '/assets/turtle-shell.png',
  width: 336,
  mouthTopPx: 176,   // ← 改这里：开口偏上就调大，偏下就调小
  shadow: true,
}
```

**校准方法**：跑一次摇卦（点「跳过动画，直接起卦」最快），看铜钱是从开口的**上方**还是**下方**冒出来的，往反方向微调这个值，每次 ±10 左右。

## 五、光照与配色

页面底色是 `#0E0F12`（近黑），强调色是暗金 `#C6A567`。素材请与这个环境协调：

- **光照**：顶光、略偏左；暗部落在右下。三枚铜钱也是这个光向，不一致会显得贴上去。
- **材质不必被现有配色限死**——你可以用骨质、青铜、玉、檀木等任何质感，只要明度不至于在整个深色页面里"跳"出来。
- 避免大面积纯白（深底上会刺眼），也避免纯黑（会和背景糊在一起，只剩一个洞）。

---

## 六、动画会怎么用这张图

素材会被放进一个容器里，由 CSS 负责运动，**素材本身只需要是一张静态图**：

| 阶段 | 对素材做什么 |
|------|--------------|
| 静置 | 极缓慢的上下呼吸位移（±5px，4.5s 循环） |
| 摇晃 | 上下摆动 3 次、幅度递减，并伴随 ±3° 轻微倾斜（0.72s） |
| 出钱 | 素材不动；三枚铜钱自 `mouthTopPx` 处出现，向上弹出后落到下方一排 |

所以**不要在图里画运动模糊或残影**，会与动画叠加成双影。

## 七、3D 模型路线（如要走）

需要我额外接入 three.js，代价：

- 新增约 600KB 依赖；页面多一块 WebGL 画布（铜钱仍是 DOM/CSS 3D，两者可共存，画布置于铜钱之下）
- 首屏会多一次模型与贴图的加载

**导出要求**（若确定走这条路）：

| 项 | 要求 |
|----|------|
| 格式 | `.glb`（glTF 2.0 二进制），单文件内嵌贴图 |
| 朝向 | +Z 朝向观察者，+Y 向上；开口朝向 **−Y** |
| 光照 | 只导出 **albedo / base color**，**不要烘焙光照与阴影**（页面自己有光） |
| 材质 | PBR metallic-roughness；金属度、粗糙度给出合理值 |
| 面数 | 建议 ≤ 3 万三角面（要撑得住低端机上的摇动动画） |
| 贴图 | 建议 ≤ 2048×2048 |
| 原点 | 模型原点放在**开口中心**，这样铜钱落点自动对齐；否则需告知开口在模型坐标系中的位置 |
