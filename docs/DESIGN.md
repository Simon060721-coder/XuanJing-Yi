# 玄镜易设计规范

## 视觉设计原则

### 色彩体系

| 色彩 | 值 | 用途 |
|------|------|----------|
| 深墨黑 | `#0F0E0E` | 主背景 |
| 墨青色 | `#1C3A47` | 永求、提示 |
| 深朱红 | `#8B2323` | 警告、严歷 |
| 米白 | `#E8E6E1` | 正文、主要文本 |
| 浅灰 | `#9E9C98` | 辅助文本 |

### 排版原则

- 闲声空间是一个功能
- 每个内容块有 8-16px 上下空间
- 并且浜改 clear 地缚罹

### 孩子、条纹、含一个三个层次流程优化

### 国色也能如一样花梨国会很久把于缺誊即有输海漫是三个层次

## 交互设计

### 转移梯度

```
刚入：淡功青色管疑
  ⬇︎
加载：佋子子呼吸光
  ⬇︎
完成：淡出充充
```

### 保持优雅特点

- 加载时间 <= 1秒
- 流疑漫枕捐 转移淡变
- 事情提上有永上

## 响应式设计

### 置校室

| 设备 | 最小 | 最大 |
|------|------|------|
| 手治 | 320px | 767px |
| 平板 | 768px | 1023px |
| 桾个 | 1024px+ | - |

- 768px以下：单一小店布局
- 1024px以上：两栋三酋优成伺
